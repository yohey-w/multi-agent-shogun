### 推奨1. 🥇 殿の🚨要対応トラッカー（放置日数監視）
**課題**: cmd_040が21日、cmd_047が12日放置。dashboard.mdを殿が読む以外の検知がない。
**案**: 家老が日次で dashboard.md 🚨要対応 を棚卸し→発生timestamp＋経過日数を算出→DAY≥3で薄いリマインド、DAY≥7で強リマインド、DAY≥14で棚卸し提案を dashboard 冒頭に挿入。
**根拠cmd_ID**: cmd_040 (21日), cmd_047 (12日), cmd_045/046 (12日), cmd_055 Chrome Web Store 連絡先メール。
**ROI**: 実装コスト小（家老の日次タスク追加）／効果大（殿の忘却＝累積コスト回避）。**最優先**。

### 推奨2. 🥈 Chrome拡張 E2E自動検証スキル (extension-e2e-verifier)

**根拠cmd_ID**: cmd_068 (phase3 UI E2E), cmd_069 (実画像3枚), cmd_071 (WebP→PNG), cmd_075 (Ollama Vision), cmd_078 (icon読込)。
**ROI**: 着手コスト中（足軽2号〜3号で1–2cmd）／回収は拡張の生涯に渡る。B1ボトルネックを直接削減。

### 推奨3. 🥉 Chrome Web Store ワンショット公開パッケージャ

### 推奨4. ブランチ整理 Auto-PR スキル (branch-sync-helper)
